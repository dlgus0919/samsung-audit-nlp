# 감사보고서 HTML 파서 구현 요약

요청하신 `환경세팅_가이드.docx`의 step 5 파싱 요구사항을 반영해 `html_parser.py` 구현 및 테스트를 완료했습니다. 

## 구현 위치
* `src/parser/__init__.py`
* [src/parser/html_parser.py](file:///Users/june_kim/samsung_audit_nlp/src/parser/html_parser.py)

## 주요 구현 사항
1. **인코딩 처리**
   * 기본적으로 `euc-kr`를 사용하되 실패할 경우 `cp949`로 Fallback 하도록 구현했습니다. 최후의 경우 `errors="replace"` 조건으로 안전하게 불러오도록 처리했습니다.
   
2. **섹션 분리 (텍스트/키워드 단위 추출)**
   * `<h1>` ~ `<h4>` 구조 대신 테이블 안의 단락(`p`, `span`, `td`) 텍스트를 재결합한 다음, 키워드 매칭(예: "감사의견", "(첨부)재 무 제 표")을 이용해 구획을 나누었습니다.
   * 연도별(2014년~2024년)로 섹션 등장 패턴(`감사의견` → `감사의견근거` → `핵심감사사항`)이 다르거나 태그 구성이 중첩되는 특성을 분석해 유연한 슬라이싱 로직 `_extract_audit_sections`, `_extract_fs_sections` 를 적용했습니다.

3. **테이블 변환 (`pd.DataFrame`)**
   * HTML 내 `<table>`을 순회해, 공란과 엔터를 정제한 뒤 DataFrame으로 일괄 변환합니다. `extract_tables()` 함수가 이를 전담합니다.
   * `extract_financial_tables()`를 추가 구축하여 `['자산', '부채']` 등의 키워드 빈도를 스코어링해, 가장 적합한 테이블을 `balance_sheet`, `income_statement`, `cash_flow`로 자동 스크리닝하여 매핑합니다. 

4. **단일/다중 보고서 추출 파이프라인**
   * `parse_single_report()`로 특정 연도의 감사보고서를 딕셔너리로 파싱.
   * `parse_all_reports()`로 전체 `.htm`, `.html` 파일들을 순회하여 정리된 목록(List[dict])을 오름차순 반환할 수 있도록 연결했습니다.
